Sound Keys Play


Web Application


Sound Keys Play is an interactive application that maps alphabetical keys to unique sounds and colorful visual circles. As users press keys, the app tracks their input, allowing them to replay sequences to create musical compositions and dynamic color patterns. It was built using Howler.js for audio playback, Paper.js for rendering vector graphics, and Vanilla JavaScript to handle key recording and playback functionality.

Guess That Color Game


Web Application


Guess That Color is an interactive game that challenges players to identify the correct color tile based on displayed RGB values. With both easy and hard modes, the game tests and strengthens players' understanding of RGB color theory. It was developed using Vanilla JavaScript, HTML, and CSS.
